\# ThreatLyst API Documentation



\## Overview



ThreatLyst is an AI-powered Security Operations and Threat Investigation Platform.



The backend API provides capabilities for:



\- User authentication and role-based access control

\- Security-event ingestion

\- AI-assisted event analysis

\- Detection-rule processing

\- Alert management

\- Incident management

\- Threat intelligence

\- MITRE ATT\&CK intelligence

\- API-key management

\- Audit logging

\- Notifications

\- Security reporting

\- Operational metrics

\- Health and readiness monitoring
